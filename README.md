# Geospatial Big Data Analysis in R

This repository accompanies a tutorial on using **Sparklyr**, **Apache Sedona**, and **Delta Lake** for scalable geospatial data analysis in R. It’s aimed at R users working with geospatial datasets that are too large for conventional libraries like `sf` or `raster`.

🔗 Read the full tutorial here: [https://rog33zy.github.io/apache-sedona-r-tutorial.github.io/](https://rog33zy.github.io/apache-sedona-r-tutorial.github.io/)
